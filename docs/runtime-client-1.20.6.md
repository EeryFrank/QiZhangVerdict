# Minecraft 1.20.6 图形客户端验证

两组均使用 Windows 和 Java 21。Fabric 成品 SHA-256 为 `984a9ba2699008f857b2dc4679319944b1fdc7e2c32fcda9bd59d0e623eba59e`，NeoForge 为 `a669cd344d41f6f79bbb3e19a0555030cc7d3da271ef8b97bc5281d50b78e077`。客户端与服务器中的实际副本逐一核对相同字节。NeoForge 使用固定官方安装器生成映射、资源及补丁库，以 `cpw.mods.bootstraplauncher.BootstrapLauncher` 和 `--launchTarget forgeclient` 启动；安装结果退出 0。生成库记录本地 SHA-256 与 ZIP CRC，上游未提供的生成文件校验值不作推断。

服务器从全新配置、世界和账号状态启动。13 项严格默认策略及 42 条规则在运行前后逐字节不变，包含必需配套客户端、必需设备报告、`vm.action=DENY`、同 IP 最多三人和同 IP 同设备最多一人。此处测试单个真实客户端持续在线；并发限制、名单增删、模糊规则和处罚用例在[独立 TCP 报告](runtime-server-1.20.6.md)中记录。

收到并保存设备关联后才开始计时。两次带独立标记的控制台查询分别证明玩家仍在线、生存模式已恢复、严格策略生效；两次查询之间持续在线至少 60 秒。客户端正常关闭，服务器正常停止，测试端口 25741、25742 均已释放。

整理证据时，在内存中重新读取 Windows 安装标识及各服作用域，独立计算预期摘要，与测试 UUID 的唯一设备关联记录比较。两组均匹配，同一安装标识在不同服务器作用域下产生不同摘要。公开文件只保留布尔值和计数，没有公开安装标识、作用域、实际设备摘要或账号状态。这些信号仍可由被修改的客户端伪造，不是可信硬件证明。

22 份附件按明确清单复制，原字节和散列已复核；实际私密值与凭据形态扫描均无命中。没有公开世界、账号状态、完整启动参数、Minecraft 或第三方 JAR。两份原始运行结果的 `formalAcceptancePassed=false` 保持原样；Codex 的截图检查单独记录，不代替用户正式验收。

本轮只覆盖这两组本机离线认证夹具，不证明正版账号认证、Forge 1.20.6、插件服互通、代理、多人负载、真实虚拟机攻防或全部作弊检测效果。新成品尚未作为测试版发布；[构建及包内核心检查](adapter-1.20.6.md)与游戏运行证据分别记录。
