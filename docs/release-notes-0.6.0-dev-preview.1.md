# 七章的裁决 0.6.0-dev-preview.1

新增 Minecraft **1.17.1 Fabric / Forge** 两份 `0.6.0-dev` 模组，要求 Java 16；连同保留原字节的 23 份历史组件，合集共 **25 个独立 JAR**。依赖、安装、散列与五代对应源码见[安装指南](preview-0.6.0-dev-preview.1.md)，每个实例只装匹配的一份。

两份新包各通过 104 项包内核心检查、26 组 TCP 准入，以及默认策略下报告接受后超过 60 秒的图形客户端验证。截图已打开检查，客户端和专服正常退出 0；用户正式验收尚未完成。见[构建](adapter-1.17.1.md)、[专服](runtime-server-1.17.1.md)和[客户端](runtime-client-1.17.1.md)。

Fabric 首次模型初始化崩溃仍保留：无 Guard 对照和同包复测成功，但根因未定。Forge 的标准通道挑战与日志适配问题已修复，并以最终包重跑；旧失败不会被通过记录替代。

新包首次默认 **44 条规则（40 DENY、4 ALERT）**，新增 `dualviewxray`、`simplexray`。同名普通模组标识不作默认拒绝，现有名单、白名单、OFF 和删除项不自动回填；按[目录流程](catalog.md)审阅后显式合并。旧组件及其默认规则保持不变。

同 IP／设备限额、可编辑 GLOB 黑白名单、账号与设备关联处罚和 VM 策略继续保留。客户端自报可被伪造，默认名单不是全市场作弊数据库。Grim、AntiXray 另行安装；本轮不证明 1.17.1 插件服互通、正版认证、真实 VM 对抗、负载或全部第三方兼容。

原创实现采用 **GPL-3.0-only**。提供 LICENSE、NOTICE、SHA256 校验文件及五代对应源码 ZIP，四份历史源码保留原字节。本说明随冻结源码分发；最终标签 CI、两站发布和匿名下载验证以发布回执为准，配额未启动的任务不计通过。
