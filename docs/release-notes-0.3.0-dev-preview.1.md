# 七章的裁决 0.3.0-dev-preview.1

新增 Minecraft 1.19.2 的 Fabric / Forge、1.20.4 的 Fabric / Forge / NeoForge 适配，并修复 Bukkit 登录重载时旧挑战覆盖新挑战、NeoForge 1.20.4 客户端初次挑战接收的时序问题。

本合集提供 18 个独立安装包：12 个原样保留的 `0.2.0-test.1` 模组、Bukkit `0.2.1-dev` 和五个新增 `0.3.0-dev` 模组。按游戏版本、加载器选择一个服务端实现和匹配的客户端模组。完整表格、Java 要求、依赖和升级步骤见[安装指南](preview-0.3.0-dev-preview.1.md)。升级前备份配置，保留 `accounts.state`、`server-id.txt` 和管理员规则。

五个新模组分别完成 97 项成品内核心检查、26 项专服连接检查与严格默认配置下的真实客户端验证。新 Bukkit 另完成 97 项成品内核心检查、两版共 52 项连接检查和受控登录重载回归。旧 12 个模组沿用其相同散列的历史验证；失败尝试与测试工具告警保留，准确范围见[验证汇总](../outputs/validation-0.3.0-dev-preview.1.json)。

默认名单仍为 37 条，黑白名单、GLOB 规则和 IP / 设备配额可配置。名单不是全市场数据库；客户端报告、设备摘要和虚拟机信号不是不可伪造的硬件认证。Grim 与矿物混淆组件独立安装，本预览不代表所有游戏小版本、第三方整合包或作弊类型均已验证。
