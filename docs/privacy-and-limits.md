# 数据、信任与防护边界

客户端只在收到本服的合法版本挑战后，在有界后台任务中读取已加载模组 ID、已选资源包 ID/文件名（不一定是界面显示名称）、粗略虚拟机类别和设备哈希。不存在云端遥测、进程扫描、远程文件上传、屏幕采集、MAC/硬盘序列号上传或内核驱动。

Windows 设备标识取系统安装 MachineGuid，Linux 取 machine-id；只在本地与本服公开 `server-id.txt` 范围标识一起 SHA-256 后上报。服务端收不到原始安装 ID。读取失败时使用模组配置目录里的随机安装 ID；回退会削弱跨启动器/重装关联能力。macOS 当前使用回退。安装本客户端前，服主应向玩家说明这些字段、封禁规则、保存范围和申诉方式。

服务端保存实际连接 IP、账号 UUID、最近登录时间、设备哈希关联和处罚原因；原始 IP 是执行 CIDR 和滚动配额所必需，不只是匿名统计。IP 账号历史按窗口清理；设备关联和永久封禁目前没有自动保留期限，需要服主管理/备份。不要公开发布 accounts.state，也不要把散列称为完全匿名数据。

设备哈希不是可信认证：修改客户端可以提供任意设备值，改名或伪造模组列表也可以绕过客户端自报规则。nonce、防重放、版本检查和长度限制只能保护协议处理，不能证明客户端没有作弊。服务器固定范围避免普通玩家仅通过切换域名别名改变设备标识；独立服务器默认随机生成不同范围以减少跨服关联，但恶意服务器可以复制他服公开范围，不能保证对恶意服不可关联。

虚拟机依据 manufacturer/model/BIOS 或 Linux DMI 的少量类别启发式判断，不上传这些原始文本。不会把 Java 虚拟机名称当作 OS 虚拟机，也不会凭 Windows HypervisorPresent/VBS 单项封禁。系统隐藏或伪造信息可以绕过，未知探测结果默认仅告警。因此这里是“拒绝报告已知虚拟机指标”，不是保证禁止一切虚拟机。

严格模式等待报告时限制行动。插件取消移动、交互、背包、拾取/丢弃、战斗与命令；模组临时设置为旁观并锁定位置，在报告成功或退出后恢复原模式。1.16.5 及更新版通过必需的 Mixin 拦截原版命令分发器，1.12.2 Forge 使用执行前可取消的原生 CommandEvent；两种路径都限制待验证的 OP。这是进入世界后的限制，客户端仍可能先收到区块/实体信息，不是登录配置阶段的完全信息隔离。其他模组自行处理的网络动作需要其自身权限检查。模组服突然崩溃可能把临时旁观模式保存进玩家数据，管理员需恢复原模式；正常退出会恢复。高要求服应结合服务端信息隐藏，并进一步实现更早的协议准入。

Paper/AntiXray 主要减少未暴露矿物的真实区块信息。暴露矿物、实体 ESP、种子推导、自定义维度/未配置模组矿物、距离与性能取舍都有边界。大量挖矿不作为单独永久封禁依据。Grim 在 Paper/Fabric 提供行为检测，改变飞行、移动、攻击距离、碰撞或维度机制的整合包仍需多人实测。

账号与设备关联可以连带封禁同一设备上的其他账户；共用电脑/网吧也可能共用标识，服主需告知并处理申诉。IP 配额不判定用户是同一个人，家庭 NAT、校园网和移动运营商出口可能共享 IP。当前没有按家庭单独配置更高配额的专用界面，可调整整体限制或在后续添加按网段覆盖。

在线模式或可信认证必须保障 UUID 的账号所有权。离线服及未保护的代理转发会削弱身份/IP规则；本项目不替代外部登录认证。当前账号历史在 Minecraft JOIN 时确认，未对接 AuthMe 等登录插件的认证完成事件，未认证昵称也可能占用滚动账号配额。代理后端应只允许可信代理接入并正确验证转发，本项目没有实现 Velocity/Bungee 的边缘独立插件，也不将单服状态自动同步到多个子服。
