# 0.1.0 首批验收记录

验收日期：2026-09-25。首批目标为 Java 版 1.20.1 / 1.21.1。最终产物散列、逐项结果及原始证据路径在项目 `outputs/validation.json`（发行 ZIP 根目录的 `validation.json`）。散列不同的早期测试只作历史记录，不计入最终 JAR 的启动验收。

## 已完成的验证层次

核心有 55 项安全回归，涵盖并发 IP/设备配额、滚动账号历史、CIDR、原子保存、事务重载、黑白名单、模糊匹配预算、关联封禁和分别解封、nonce 与报告限额。它们证明核心函数的行为，不等于所有 Minecraft 适配器均经过完整联机验证。

Bukkit 最终 JAR 在 Purpur 1.20.1 build 2062 / Java 17、Purpur 1.21.1 build 2329 / Java 21 上各通过 25 项真实 TCP 联机检查，正常 stop 退出 0。两组包含严格报告超时、同 IP 同设备 1 人、不同设备 3 人及可调 2 人、账号/设备封禁和解封、名单修改、CIDR、已知 VM 信号拒绝，以及 OP 在报告前后分别禁止/允许执行命令。

这两组测试还在无矿石的受控平坦世界读取服务端真实区块包，观测到 16 种伪装矿石状态。1.20.1 的区块缓冲区有最多 20 字节零填充，夹具按原版主世界的 24 段读取并验证剩余字节全零；没有把尾部填充误当新区段。此项证明混淆数据已发送，不是实际透视客户端、实体隐藏或长期挖矿效果测试。

Bukkit 1.21.1 的无效首启配置也单独做了失败关闭验证：插件保持监听，真实 TCP 客户端被拒绝且未进入 PLAY，服务端正常退出 0。最终 Fabric 1.21.1 成品渲染客户端连接最终插件服后，56 秒时仍在线、保持生存模式且设备关联落盘；客户端与服务端都正常退出 0。

四个模组平台的最终成品均通过专服启动、真实控制台状态命令和正常停服，退出码 0。Fabric 1.21.1 最终成品另通过 26 项协议用例，包括真实 OP 指令隔离、`device:哈希` 解封、`legacy:mod:meteor-client` 默认规则删除与重新添加。两版实际 Brigadier 命令树各有 7 项解析/权限回归通过。依赖加载判定已用真实初始化标记修正，Forge / NeoForge 均明确记为未加载 Grim。

最终 Fabric 1.21.1 成品客户端连接同版专服，在 38 秒时仍在线，已恢复生存模式并保存设备关联；单人房主使用 local 连接也验证成功，保存为生存模式，正常关闭。三轮客户端与两个专服全部退出 0。客户端报告器还直接针对最终 JAR 验证了稳定范围哈希、异服范围隔离、异步探测、协议往返、过期回调抑制及 20 次快速重载合并。其他三个加载器的真实客户端多人游戏尚未验收。

## 外部组件与已知告警

- Paper 系 1.20.1 固定 Grim 2.3.71；1.21.1 固定 Grim 2.3.73。2.3.73 在本次 Purpur 1.20.1 的登录压缩链发生 PacketEvents 登录拒绝，未作为该版本默认安装组合。2.3.71 在正常压缩阈值 256 下完整通过上述测试。后续升级应重新验收。
- Fabric 1.21.1 的 Grim 额外需要兼容的 Cloud beta.10 和 SQLite JDBC。Fabric 1.20.1 的 Grim 检测能启动，但其自带 `/grim` 命令因缺少兼容 Cloud 构建不可用；不影响 `/qzverdict`。
- Fabric 的上游 PacketEvents 仍打印非致命 refmap JSON NPE；其内嵌 Mixin 管理器返回空 refmap 文件名，实际字节码归属证据在 `integrations/upstream-runtime-notices.json`。通过启动验收不表示日志没有错误，也不证明第三方引擎的全部检测准确。
- 测试用 minecraft-protocol 在 1.21.1 部分配方数据上出现 ArmorTrimMaterial 解析告警；没有把该第三方客户端当成完整渲染客户端，原始日志保留。自定义报告与本次检查分别按实际断言判定。
- Forge / NeoForge 配置包含 AntiXray，没有 Grim 行为预测引擎。各平台能力不能等同。

所有本次服务端运行都使用隔离测试目录和 loopback 地址。离线账号只用于本机自动测试，不是生产服务器的身份认证建议。原始运行数据、世界、下载缓存和日志保留在 `E:\CodexTemp\QiZhangGuard`；这是早期临时项目名，不影响成品名称。
