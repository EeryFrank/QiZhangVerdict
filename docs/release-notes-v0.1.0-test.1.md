# 七章的裁决 · QiZhang's Verdict — v0.1.0-test.1

首个公开测试版，优先覆盖 Minecraft Java 1.20.1 / 1.21.1。安装包内部版本为 `0.1.0`；本次发布标签为 `v0.1.0-test.1`。

## 本版功能

- 同 IP、同设备默认最多 1 个在线账号；不同设备默认最多 3 个，可改为 2。
- IP/CIDR 登录白名单、拒绝名单、滚动账号数和登录频率限制。
- 管理员增删黑白名单，支持精确匹配及 `*` / `?` 模糊匹配。
- 规则命中可关联封禁账号、设备及已关联账号；支持分别解封。
- 配套客户端报告模组、已选资源包、设备哈希与虚拟机类别；严格模式等待报告时限制操作。
- 独立安装的 Grim / AntiXray 固定依赖、来源和校验值，以及可选处罚联动配置。

## 安装包

`QiZhangVerdict-0.1.0.zip` 包含 Bukkit 插件、Fabric 1.20.1、Forge 1.20.1、Fabric 1.21.1、NeoForge 1.21.1 五个 JAR、说明与验收记录。选择对应平台安装；不要把所有 JAR 一起放进同一个服。源码另见 `QiZhangVerdict-0.1.0-sources.zip`。

默认设备策略要求玩家安装匹配的配套模组，插件服玩家也一样。Fabric 另需 Fabric API。第三方反作弊组件不混装进自研 JAR，请按 `integrations/README.md` 安装。

## 本次验证

核心 55 项安全回归通过；两个版本的命令树解析各 7 项通过。Bukkit 在两版 Purpur 上各通过 25 项真实 TCP 检查，含假矿石区块和严格准入。四个最终模组专服启动、状态命令与停止通过；Fabric 1.21.1 另通过 26 项协议检查。最终 Fabric 1.21.1 渲染客户端的单人游戏、模组服和插件服连接均通过，进程正常退出。

具体 JAR 散列与验证范围见安装包内 `validation.json` / `docs/validation.md`。构建流水线与本机真实运行证据分别记录，不能相互替代。

## 测试版边界

设备码和客户端清单可被修改过的客户端伪造；VM 探测是启发式，黑名单不覆盖全部作弊。Forge / NeoForge 当前组合有 AntiXray，尚无 Grim 行为引擎。Grim Bukkit 在 1.20.1 单独固定已验证的 2.3.71；Fabric 1.20.1 的 `/grim` 命令暂不可用。其他 Minecraft 版本、其他三个加载器的真实客户端、大型整合包和长期多人性能尚未验收。

这是公开测试版本，发布页不代表上述未测试范围已经兼容。反馈时请提供游戏版本、服务端/加载器、JAR 散列和去除账号/IP/设备标识后的日志。
