# v0.1.1-test.1

本版第一方代码采用 **GPL-3.0-only**，安装包与源码一同公开。每个独立 JAR 内含 LICENSE、NOTICE，模组描述符标记同一许可证；Gradle Wrapper 及独立第三方依赖保留原许可。

修复 Forge 1.20.1 配套模组连接后 20 秒报告超时的问题：Forge 的事件按发送端命名，原适配器把两种方向接反；现使用正确事件并限定 PLAY 阶段。补齐资源元数据后，Forge 首屏警告消失，真实客户端可以直接进入服务器并完成验证。

本版提供 Bukkit、Fabric 1.20.1、Forge 1.20.1、Fabric 1.21.1、NeoForge 1.21.1 五个测试 JAR。四端均完成严格默认策略的真实客户端与专服验证；最终 GPL 插件另有现代两版共 54 项真实连接断言。旧版五版共 60 项实测使用许可调整前候选，最终包的类文件与其逐字节相同，未冒称旧版已经用新散列重跑。核心 55 项安全回归、目录 25 项工具回归及生产解析器检查通过。

GPL 客户端复测中有登录前超时，使用相同成品及配置重试后通过；失败日志和通过轮次分别保留，原因尚未确定。

新增 31 个源码可核验标识的可选扩展目录、来源核验和保留管理员配置的合并工具。名单可增删、支持通配匹配；同 IP 同设备默认 1 人、不同设备总计 3 人，规则处罚支持账号与设备关联封禁。这些能力仍受客户端自报可伪造的边界限制，不宣称覆盖全部作弊或不可绕过地识别设备／虚拟机。

请按平台选择一个服务端 JAR 和对应客户端模组；独立安装的 Grim / AntiXray 与固定版本说明见集成文档。旧版插件准入实测不代表对应客户端模组已经全部完成。1.18.2 / 1.19.4 的开发适配不包含在本次五个安装包中。

验收详情见 [0.1.1 报告](validation-0.1.1.md)。旧版发布文件保持不变，两站原发布说明已注明 Forge 0.1.0 的实测问题。
