# 七章的裁决 0.5.0-dev-preview.1

新增 Minecraft **1.20.6 Fabric / NeoForge / Forge** 三份 `0.5.0-dev` 模组，要求 Java 21。连同保留原始字节的既有 20 份组件，本合集共 **23 个独立 JAR**。加载器依赖、安装步骤、SHA-256 和对应源码见[安装指南](preview-0.5.0-dev-preview.1.md)。每个实例只安装匹配的一份。

新增三份分别通过 102 项包内核心检查、26 组连接检查及默认策略下超过 60 秒的真实图形客户端验证。三份截图已实际打开审阅；用户正式验收尚未完成。Forge 初次 Mixin 启动失败与后续机器人未收到挑战的失败记录均保留；产品修复和测试工具调整分别说明，后一次失败原因未唯一确定。证据见[本轮汇总](../outputs/validation-0.5.0-dev-preview.1.json)、[Fabric/NeoForge 运行记录](runtime-server-1.20.6.md)、[Forge 运行记录](runtime-server-forge-1.20.6.md)。

本次新增成品首次默认 **42 条规则（38 DENY、4 ALERT）**，新增精确 ID `gateclient`、`genshin`、`meteor-crash-addon`。既有两份 1.21.11 仍默认 39 条，其余 18 份仍默认 37 条。管理员现有名单、白名单、`OFF` 和删除项不会自动覆盖，可按[目录流程](catalog.md)审阅后显式合并。

同 IP／设备配额、可编辑 GLOB 黑白名单、账号与设备关联处罚及 VM 策略继续保留。客户端自报不是不可伪造的硬件认证，默认名单也不是全市场作弊数据库。Grim、AntiXray 另行安装；本轮不证明 1.20.6 插件服互通、正版认证、真实 VM 对抗、多人负载或所有第三方兼容性。

原创实现使用 **GPL-3.0-only**，附 LICENSE、NOTICE、SHA256 校验文件，以及按组件来源分别提供的四代对应源码 ZIP。三份历史源码保留原始字节与发布入口；本次源码只对应新增三份，不将它表述为全部旧成品的可复现源码。[开发提交 CI](ci-development-1.20.6.md)和最终标签 CI 分别记录，发布状态与下载验证以本页后续结果及回执为准。
