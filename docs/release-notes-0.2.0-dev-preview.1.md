# QiZhangVerdict 0.2.0-dev-preview.1

七章的裁决旧版适配测试包，采用 **GPL-3.0-only**，公开源码和安装包。

- 新增 Forge 1.12.2，以及 Fabric / Forge 1.16.5、1.18.2、1.19.4 的七个模组安装包。
- 附已有 Bukkit 0.1.1 插件，保留默认 IP/设备配额、可增删黑白名单、GLOB 模糊匹配、设备关联处罚与已知 VM 信号拒绝。
- 七种模组客户端连接匹配专服，另有 1.12.2 Forge → Paper 实测，共八个最终通过组合；严格默认配置下报告获准后在线至少 65 秒，双方正常退出。
- 提供原始日志、截图、失败与重试记录、实际执行的 QA 快照及 SHA256。1.18.2 的首次资源等待/原生崩溃原因仍未确定。

请先阅读 [安装与验收边界](preview-0.2.0-dev-preview.1.md)，按版本和加载器只选择对应 JAR。Fabric 需要另装完整 Fabric API。插件服玩家也需要客户端模组；1.8.x 尚未纳入本包。1.20.1 / 1.21.1 继续使用 0.1.1-test.1。

这是一份开发预览，JAR 内部版本为 0.2.0-dev，Bukkit 为原 0.1.1；设备和 VM 信息属于客户端自报，不承诺封锁所有外挂、透视或虚拟机。大型整合包、生产认证及真实作弊误报率仍待验证。
