# 七章的裁决 0.4.0-dev-preview.1

本合集保留原 18 个安装包的精确字节，增加 Minecraft 1.21.11 的 Fabric / NeoForge 两份 `0.4.0-dev` 模组，共 20 个独立 JAR。新适配要求 Java 21，分别使用 Fabric Loader 0.19.5 + Fabric API 0.141.6+1.21.11、NeoForge 21.11.45。安装选择、散列和升级步骤见[安装指南](preview-0.4.0-dev-preview.1.md)。

新增两份成品各完成 99 项精确 JAR 核心检查、26 组匹配专服准入检查，以及默认 13 项策略、39 条目录下至少 60 秒的真实图形客户端检查。原始失败记录与测试环境边界保留，详见[构建说明](adapter-1.21.11.md)、[专服报告](runtime-server-1.21.11.md)和[真实客户端报告](runtime-client-1.21.11.md)；两份 PNG 由 Codex 实际打开核验，用户正式验收仍未完成。通过这些检查不等于真实虚拟机攻防、正版登录、多玩家负载或全部第三方兼容性已验证。

只有两份新增 1.21.11 成品首次安装默认 39 条规则（35 `DENY` / 4 `ALERT`）；继承的 18 份原件仍默认 37 条。新增精确 ID 为 `ferox`、`wurstplusthree`。现有管理员配置、`OFF` 与删除项不会自动恢复；可通过[目录工具](catalog.md)审阅后显式合并，勿直接覆盖现有规则。

IP / 设备配额、关联账号与设备处罚、VM 策略及 GLOB 黑白名单继续保留。客户端自报不能充当不可伪造的硬件认证，名单不是全市场作弊数据库。Grim、AntiXray 等另行安装，历史组合的成功不外推到本次新版本。

[开发提交 CI](../outputs/ci-development-1.21.11.json)记录 GitHub 12 项作业成功、GitLab 12 项额度拒启。最终标签 CI 与附件下载结果以发布页面和后续回执为准，开发流水线不替代最终标签检查。原创源码采用 **GPL-3.0-only**，发行附件包含 LICENSE、NOTICE、对应源码与 SHA256 校验文件。

合集保留组件原始源码关系：新两份对应本次源码，旧六份对应 0.3 标签，旧 12 份对应 0.2 标签；[对应源码及原始 ZIP](preview-0.4.0-dev-preview.1.md#对应源码与历史原件)单独列明，三个源码 ZIP 分别提供。本次 39 条源码不能冒称可重建旧 37 条成品的原字节。各项事实分别列入[验证汇总](../outputs/validation-0.4.0-dev-preview.1.json)。
